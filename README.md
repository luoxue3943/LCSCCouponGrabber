# LCSC-Coupon-Grabber

一个用于嘉立创商城活动页面的轻量级 Tampermonkey / Userscript 抢券辅助脚本。

脚本会从页面顶部开始，从上到下查找并依次点击 **「立即抢券」**，自动跳过已经领取后显示的 **「去使用」**，并在每次真实点击之间保持 **1 秒**间隔。

对于 **PLUS 专区**，由用户在开始前自行选择是否参与；开关默认关闭。

## 功能

- 仅运行于嘉立创商城活动页
- 页面右上角提供悬浮控制面板
- 手动点击「开始抢券」后运行
- 自动回到页面顶部
- 自动从上到下扫描
- 自动向下滚动页面
- 自动触发页面懒加载
- 每个候选优惠券只处理一次
- 每次真实点击间隔 1 秒
- 仅点击文字为「立即抢券」的目标
- 自动跳过「去使用」
- PLUS 专区可选，默认关闭
- 运行期间锁定 PLUS 开关，避免中途改变规则
- 到达页面底部后自动进行多次检查
- 支持随时停止
- 显示当前状态和已点击数量

## 支持页面

脚本仅匹配：

```text
https://www.szlcsc.com/huodong.html*
```

同时脚本内部还会再次检查 URL 前缀：

```javascript
location.href.startsWith(
  "https://www.szlcsc.com/huodong.html"
)
```

因此不会在嘉立创商城其他页面运行。

## 安装

先安装支持 Userscript 的浏览器扩展，例如：

- Tampermonkey
- Violentmonkey

然后新建一个 Userscript，将：

```text
lcsc-coupon-grabber.user.js
```

中的内容完整复制进去并保存。

打开：

```text
https://www.szlcsc.com/huodong.html
```

页面右上角会出现「嘉立创抢券助手」。

## 使用

1. 打开嘉立创商城活动页。
2. 根据需要决定是否开启「PLUS 专区」。
3. 点击「开始抢券」。
4. 脚本自动回到页面顶部。
5. 从上到下寻找「立即抢券」。
6. 每次点击后等待 1 秒。
7. 自动继续向下滚动并检查新的优惠券。
8. 到达页面底部后再次检查。
9. 没有新的可抢券后自动结束。

运行过程中可以随时点击「停止」。

## PLUS 专区

「PLUS 专区」开关默认关闭。

### 关闭

脚本会跳过识别为 PLUS 专属的优惠券。

### 开启

脚本会将 PLUS 专属优惠券和普通优惠券一起处理。

PLUS 判断只根据当前优惠券卡片自身的文字，例如：

```text
PLUS专属券
PLUS专享券
PLUS会员券
PLUS优惠券
```

不会单纯因为页面侧边栏存在「PLUS专区」文字而把其他优惠券误判为 PLUS。

## 点击规则

脚本只会点击文本完全等于：

```text
立即抢券
```

的目标。

例如：

```text
立即抢券   -> 点击
去使用     -> 跳过
已抢光     -> 跳过
已领取     -> 跳过
查看详情   -> 跳过
```

真正执行点击前还会重新检查一次按钮文字。

如果按钮在等待期间已经由：

```text
立即抢券
```

变成：

```text
去使用
```

本次点击会自动取消。

## 点击间隔

默认间隔：

```javascript
clickIntervalMs: 1000
```

单位为毫秒：

```text
1000 ms = 1 秒
```

如需修改，可自行调整：

```javascript
const CONFIG = {
  clickIntervalMs: 1000,
};
```

## 隐私

本脚本：

- 不收集用户信息
- 不发送额外网络请求
- 不上传 Cookie
- 不读取账号密码
- 不使用第三方统计
- 不包含远程代码
- 所有操作均在当前浏览器页面本地执行

## 注意事项

本项目主要用于 Userscript 和浏览器页面自动化学习。

嘉立创商城页面结构可能随网站更新发生变化。如果目标页面结构发生较大调整，脚本可能需要同步更新。

使用本脚本前，请自行确认相关活动规则和网站使用规则。因使用脚本产生的账号、优惠券、活动资格或其他问题由使用者自行承担。
